# Methods in Enzymology Examples

This directory contains template Jupyter notebooks to work through the examples presented in the paper:

> **“Processing and analyzing high-throughput microfluidic enzymology data: a practical guide to rate fitting and quality control.”** *(in review)*

## Getting Started

1. **Environment Setup**: Set up your environment following the instructions in the [Mercury repository](https://github.com/pinneylab/mercury).
2. **Download Example Data**: Download the example experimental dataset from [here](https://drive.google.com/file/d/1rLQAw7mHc4zy08sU4Uq0cvyCaGKCxnS0/view?usp=sharing) and unzip it in the same directory as the notebooks.
3. **Run Notebooks**: Open and follow the step-by-step prompts within the template notebooks to execute the workflow.

## Included Notebooks

- [`process.ipynb`](process.ipynb) – Template notebook for raw microscopy image stitching, background subtraction, chamber finding, and fluorescence quantification.
- [`analysis_mm.ipynb`](analysis_mm.ipynb) – Template notebook for initial rate fitting, background subtraction, quality-control filtering, and Michaelis–Menten kinetic parameter estimation.
